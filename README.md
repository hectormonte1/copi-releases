# copi-releases
Descargas y actualizaciones de Copi para macOS y Windows.

- **Mac** (macOS 14 o posterior, Apple Silicon e Intel): descarga el `.dmg` del release más reciente, ábrelo y arrastra Copi a Aplicaciones. Está firmada y notarizada por Apple, así que abre sin avisos de seguridad.
